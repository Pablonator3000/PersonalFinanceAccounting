# PersonalFinanceAccounting

Консольное приложение для учёта личных финансов

## Кошельки

### Каждый кошелёк содержит:

* **ID**
* **Название**
* **Валюта**
* **Начальный баланс**
* **Список транзакций**

## Транзакции

### Каждая транзакция включает:

* **ID**
* **Дата**
* **Сумма**
* **Тип**: `Income` или `Expense`
* **Описание**

## Приложение позволяет выводить агрегированную статистику.

### 1. Группировка транзакций по типу за выбранный месяц

Для указанного месяца:

* транзакции группируются по типу (`Income` / `Expense`)
* группы сортируются по общей сумме (по убыванию)
* внутри каждой группы транзакции сортируются по дате (от старых к новым)

### 2. Топ-3 наиболее крупных трат

Для каждого кошелька:

* выбираются 3 самые большие траты за месяц
* сортируются по убыванию суммы
